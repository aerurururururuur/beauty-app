# modules/references/application —— 应用层

本层放「参考检索的独立用例/策略」。

- **现状**：空。检索调用发生在 `jobs` 的 RunPipeline（经 `ReferenceProvider` 端口），本模块不重复持编排。
- **将来放什么**：若参考链路需独立策略（真实图源的本地索引/缓存、按场合×肤色的匹配打分、素材合规预检），作为用例放这里，由 `compose.ts` 装配。
- **红线提醒（2026-09-11 改写）**：`license` 字段已删除，所以**没有「必填校验」可做了** ——
  现在能预检的只剩 **`sourceUrl` 是否为空**（它是删掉 `license` 后仅存的出处线索）。
  ⚠️ 但**别把「预检通过」当成「素材合规」**：外部检索来的图**本来就没有授权可标**，
  校验 `sourceUrl` 非空只能证明「知道这张图从哪来」，证明不了「有权用」。授权仍是本模块的**未解待办**，
  见模块 README 的「已知代价」与 roadmap §13-2 的已知情变更记录。
