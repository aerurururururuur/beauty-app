# scripts/assets/ —— 实验用的人像素材

这里的**图片都被 `.gitignore` 挡在版本库外**(`*.webp` / `*.jpg` / `*.png`),只有本说明会进库。

## `face-local.webp` —— 缺省输入照片

`qwen-image-makeup.ts` 不给 `--image` 时就用它当「化妆的主体」。

| | |
| --- | --- |
| 来源 | 从网上抓的图,2026-09-15 从 `tespro/learn/blend/face-local.webp` 拷来(同一张,那个实验的基准脸) |
| 用途 | **只能本地学习/实验用**。别提交、别进演示素材、别进 demo —— 同 `tespro/learn/blend/README.md` 的红线段 |
| 规格 | 303×303 webp |

> ⚠️ **它低于接口建议的 384px 下限**(阿里云文档原文:分辨率过低可能导致生成效果模糊)。
> 拿它验「身份保没保住 / 人脸审核拦不拦」可以,**拿它评画质不行**。

换自己的照片:直接覆盖这个文件,或跑的时候给 `--image <路径>`。

> ⚠️ 另外记住:这个脚本会把照片**发给阿里云**(Base64 直传,不经第三方存储桶,但推理在对方机器上)。
> 所以别拿真人用户的自拍跑它 —— 与项目红线上「用户自拍不上传第三方」直接冲突。
